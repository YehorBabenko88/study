В независимой приёмке Base/A/B по 15 test methods: 13 PASS, 2 FAIL.
unittest сообщает failures=3: два subtest Origin/Host и один PDF OCR.
Нулевой exit от приёмки не получен; это ожидаемый отказ на дефектах продукта.

F1 — высокий приоритет: отсутствует проверка Origin/Host для записи API.
Воспроизведение: POST /v1/boards, Content-Type: text/plain,
body {"nodes":[],"edges":[],"title":"Origin audit"}.
Отдельно Origin: https://attacker.invalid при обычном loopback Host;
отдельно Host: attacker.invalid. В обоих случаях HTTP 200, запись создана.
Ожидание аудита: 400/403 для недоверенных источников/Host.
Это доказательство поведения HTTP API, не демонстрация полного browser exploit:
доступ с внешней страницы может дополнительно ограничиваться политикой браузера.
Потенциальный риск: изменение локальных данных через browser-mediated запросы
и DNS rebinding при обходе соответствующих ограничений браузера.
Место: prototype/web_app.py Handler.do_POST; аналогично следует проверить DELETE.

F2 — высокий приоритет: PDF OCR без языка ошибочно завершается успешно.
Воспроизведение: PDF с пустой/сканированной страницей, process(ocr=True),
TesseractError из-за отсутствия deu. Результат: next_page=1, status=complete,
page.text="", method=ocr_unavailable. Повторный process начинается после страницы
и не повторяет OCR. Пользователь получает пустой текст вместо retryable ошибки.
Исходный PDF сохраняется: это потеря результата/возможности штатного продолжения,
а не доказанная потеря исходного файла. Место: document_import.py process.
Ожидание: recoverable состояние и явная возможность повторить OCR после установки
языка без ручного редактирования базы. Модели/языки аудитом не устанавливались.

Следует перейти на import pymupdf с отдельно проверенной совместимостью.

Для выводов Base используются последние evidence/base логи, не первые запуски.

  python -m venv "$Repo\.qa-venv"
  & "$Repo\.qa-venv\Scripts\python.exe" -m pip install -r "$Repo\qa\requirements-windows.txt"

Для точного Base SHA используйте -SourceRoot с чистой копией Base исходников;
qa берётся из ветки аудита. Для архивов можно явно задать -SourceCommit.
Скрипт создаёт новый каталог StudyQA-GUID в TEMP, ничего не удаляет и сохраняет
логи/базу/скриншоты; при существующем EvidenceRoot отказывается работать.
Не направляйте SourceRoot на рабочую копию с пользовательскими данными.
Тесты intentionally красные до устранения F1/F2; exception/exit != 0 ожидается.
Для повторного запуска укажите новый EvidenceRoot, не очищайте старые данные.
