# Data Rights, Privacy and Responsible Use v0.1

1. Every imported dataset must have its own provenance manifest (source URL, original author/attribution, license, version, date, redistribution and commercial use assessment).
2. Do not presume that Wiktionary, word lists, translated examples or voice recordings all share one license. Respect attribution/share-alike and audit derivative works.
3. Avoid sending learner utterances, personal mnemonic scenes or room camera feeds to third parties without explicit informed consent. Local processing preferred. Provide provider inventory and retention controls.
4. If AR uses room cameras, default to on-device inference; no background uploading. Request microphone/camera permissions for each relevant feature.
5. Provide user export/delete, retention settings, encryptable backups and access scoping. Consider GDPR lawfulness and data-subject rights for Germany/EU.
6. Minors require a separate age-appropriate design and jurisdiction-specific assessment before release.
7. Treat generated translations, phonetic analogies, scenes and pronunciations as fallible. Never silently present an invented example as verified source content.
8. Experimental personalization must be opt-in, transparent and reversible. Avoid inferring neurological diagnoses or fixed cognitive types.
9. Rate-limit provider calls; store content hashes; handle abuse, media moderation and malicious prompt injection.
10. This repository must not be integrated with unrelated finance/trading/office software or infrastructure.
